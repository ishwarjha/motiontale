# Motiontale: plan and status

*30 September 2026.*

## Purpose

Our own studio for product films, possibly open-sourced under MIT later. It checks three things before a film is shown: real product UI with provenance, every on-screen number sourced, and measured quality.

## Decisions (30 September 2026)

| Decision | Choice |
|---|---|
| Purpose | Our own use; possibly open source for others. Not sold |
| Licence | MIT, added when we decide to publish (copyright holder to be named then) |
| Unsourced numbers | Block the render. Demo data passes only as `example`, shown with an "Example" label |
| Live web-embed export | Not now: the no-clock rule stays absolute |

## What is built (30 September 2026)

| Area | Built | Proof |
|---|---|---|
| Brief | `motion-brief` skill: interview, BRIEF.md, facts.md, shotlist.md, two approval gates | contract test |
| Real UI | `motion-capture` skill + `capture.py`: pages and elements by selector at 2x, transparent crops, state patches, provenance.json, suggested facts | captured kosolve.ai: 3 captures, transparent crop verified |
| Claims | facts.md ledger; `lint.py` blocks unsourced numbers, fact rows without source/date, unlabelled examples, shots without provenance | lint self-test |
| Motion blur | 4 samples a frame, doubling with measured motion up to 64, blended in Python; `--shutter` | unit test: counts at 15, 30 and 1000 px, cap held |
| Determinism | `check determinism` (shuffled order); deterministic Chrome raster flags; `recipe.json` + `replay` | control run: 27 and 19 differing frames without the flags, 0 with them; replay IDENTICAL |
| Layout | `check layout`: minimum text size, off-frame text, overlaps, WCAG contrast, every beat | engine test: a tiny label caught; a word sinking into its mask and a popping word pass |
| Assertions | `asserts` in timeline.js: `appearsBy`, `staysInFrame` | engine test: a missing selector and an off-frame element fail |
| Sound | stems, `mux` without re-render, `check avsync` on the final file, LRA gate, true peak | engine test: audio slipped 40 ms fails avsync |
| Seams | `check seams`: frames −2…+2 at every cut | runs on multi-shot films |
| Delivery | `film.py export`: SRT/VTT (voice lines or on-screen captions), chapters YouTube accepts, poster, GIF | engine test: caption times, escaping, chapter rule |
| Long runs | `motion-director` skill: production.json gates, subagent playbook, resume, effort and render budget | contract test |
| Critique | 8-axis rubric (hook, readability, composition, motion, variety, brand, sound, polish), each beside a measured check | checks.md |
| Styles | 12: editorial, explainer, tour, vertical, keynote, morph loop, story, teaser, data story, tutorial, app preview, sizzle reel; `chart` scene and `drawPath()` | contract test; one KoSolve film per style rendered and checked (films/SMOKE-LOG.md) |
| Workspace | `audit` adds missing-recipe findings | audit self-test |

## Left out, and why

- **Code-synthesised music and effects:** real, measured sound is the point.
- **Rebuilding product screens in code:** the opposite of the real-UI rule.
- **Generated video layers under a film:** they break real UI; at most a labelled story style later.
- **Live web embed:** declined for now.
- **One house look:** every film gets its own brief, captures and look, so films don't converge on one default.
